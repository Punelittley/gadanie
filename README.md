# АРКАНУМ — Мастерская осознанного Таро и глубинного анализа

Современный, оптимизированный сайт для мастера Таро и консультанта с **интерактивной 3D-колодой на Three.js (60 FPS без лагов)**, интерактивным раскладом «Карта дня», каталогом фиксированных тарифов, честными отзывами и **полным юридическим пакетом в строгом соответствии с законодательством Российской Федерации**.

Сайт работает на чистом стеке (HTML5, CSS3, ES6 JavaScript) без сборщиков и зависимостей, **готов к моментальной публикации на GitHub Pages**.

---

## Преимущества и функционал

1. **Оптимизированная 3D-сцена (Three.js 60 FPS)**:
   - Объемная колода карт с золотыми срезами торцов и классической векторной гравюрой (без системных смайликов и эмодзи).
   - При скроллинге страницы карты эффектно разлетаются в 3D пространстве веером вдоль плавной дуги.
   - Правильный кинематографичный флип карты спереди к зрителю при нажатии.
   - Понятный и заметный интерактивный призыв: «Нажмите на карту для расклада».
2. **Интерактивный расклад «Карта дня»**:
   - База Старших Арканов с глубоким смысловым разбором, советом, предостережением и аффирмацией дня.
   - Быстрый запуск в один клик.
3. **Строгое соответствие законодательству РФ**:
   - **Статус самозанятого (НПД)**: в соответствии с Федеральным законом от 27.11.2018 № 422-ФЗ, с предоставлением фискального чека клиенту в приложении «Мой налог».
   - **Закон о защите прав потребителей**: полные реквизиты исполнителя (ФИО, ИНН), фиксированная стоимость услуг без скрытых доплат.
   - **152-ФЗ «О персональных данных»**: согласие на обработку персональных данных в форме заявки и доступная Политика конфиденциальности.
   - **Защита от ст. 159 УК РФ и закона о рекламе**: отсутствие шарлатанских обещаний («100% гарантия», «снятие порчи», «привороты»). Услуги носят информационно-развлекательный характер для саморефлексии (ст. 438 ГК РФ).
   - **Маркировка возраста 18+** в шапке, форме и футере.
4. **Удобная форма заказа**:
   - Формирование структурированной заявки с перенаправлением в Telegram мастера в один клик.

## Запуск сайта локально

Просто откройте файл `index.html` двойным кликом в любом современном браузере.

---

## Публикация на GitHub Pages (за 1 минуту)

1. Создайте репозиторий на [GitHub.com](https://github.com/new) (например, `arcanum-tarot`).
2. Отправьте файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Arcanum Tarot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/arcanum-tarot.git
   git push -u origin main
   ```
3. В настройках репозитория: **Settings** -> **Pages** -> выберите ветку `main` и нажмите **Save**.
4. Сайт будет опубликован по адресу:
   `https://ВАШ_ЛОГИН.github.io/arcanum-tarot/`

---

## Настройка данных исполнителя

1. **Ваш Telegram**: в файле `scripts/app.js` замените `'astral_tarot_master'` на ваш никнейм в Telegram (без символа `@`).
2. **Реквизиты самозанятого**: в файле `index.html` укажите ваше реальное Ф.И.О. и ИНН в блоке футера и тексте Публичной оферты.
